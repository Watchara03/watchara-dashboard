ตั้งค่า Firebase (ครั้งแรก)
ทำแค่ครั้งเดียว ใช้ได้ตลอดไปทุก device
ข้อมูลเป็น Private — เข้าถึงได้เฉพาะคุณเท่านั้น
Step 1 — สร้าง Firebase Project

ไปที่ console.firebase.google.com
กด Create a project → ตั้งชื่อ → ปิด Google Analytics → Create

Step 2 — เพิ่ม Web App + Copy Config

ใน Project → กด icon </> (Web) → ตั้งชื่อ App → Register
จะเห็น firebaseConfig = {...} → Copy ทั้งก้อนวางในช่องด้านล่าง

Step 3 — เปิด Google Login + Firestore

Authentication: Build → Authentication → Get started → Google → Enable → Save
Firestore: Build → Firestore Database → Create database → Start in test mode → Done
